# 如何管理用户和权限

这篇指南教你创建新用户、分配页面权限、修改密码。

## 前提条件

- 以 admin 身份登录
- 只有管理员可以访问"用户管理"页面

## 创建新用户

1. 点击左侧菜单"用户管理"
2. 点击"新增用户"
3. 填写表单:

| 字段 | 说明 | 示例 |
|------|------|------|
| 用户名 | 登录名，唯一 | `zhangsan` |
| 显示名称 | 页面右上角显示的名字 | `张三` |
| 角色标签 | 描述性标签 | `钳工` |
| 密码 | 至少 6 位 | `123456` |
| 是否管理员 | 管理员可访问所有页面 | 取消（普通人） |
| 是否激活 | 关掉可禁用账号 | 开启 |

创建后用户出现在列表中。

## 分配页面权限

1. 在用户列表中找到目标用户
2. 点击"权限"按钮
3. 对每个页面设置:
   - **不可见:** 两个开关都关闭，用户看不到这个菜单项，也无法通过 URL 直接访问
   - **只读:** 只开"可见"，用户可以查看列表和详情，但不能新增/编辑/删除
   - **可编辑:** 两个开关都打开，完整权限

**常见权限组合:**

| 角色 | 仪表台 | 订单 | 客户 | 库存 | 图纸 | 工艺 | 用户 | 通知 | 设置 | 外协 |
|------|--------|------|------|------|------|------|------|------|------|------|
| 车间工人 | 可见 | 可编辑 | 只读 | 可编辑 | 只读 | 只读 | 不可见 | 可见 | 不可见 | 不可见 |
| 设计师 | 可见 | 只读 | 不可见 | 不可见 | 可编辑 | 可编辑 | 不可见 | 可见 | 不可见 | 不可见 |
| 仓管 | 可见 | 只读 | 不可见 | 可编辑 | 不可见 | 不可见 | 不可见 | 可见 | 不可见 | 不可见 |

## 管理员防锁死

管理员在给自己配置权限时，"用户管理"页面的开关被锁定为开启状态。这是为了防止管理员误操作把自己锁在用户管理页面外面。

## 删除用户

1. 找到目标用户
2. 点击"删除"

限制: 不能删除最后一个管理员。如果只有一个 admin 账号，删除会报错。

## 修改密码

任何用户都可以修改自己的密码:

1. 点击右上角用户名 → "系统设置"
2. 找到"修改密码"区域
3. 输入当前密码和新密码（至少 6 位）

管理员也可以通过用户管理页面重置他人密码。

## 故障排除

| 问题 | 解决 |
|------|------|
| 用户登录后看不到任何菜单 | 检查是否分配了至少一个 page_key 的 can_view |
| 用户能看到页面但无法操作 | 检查 can_edit 是否开启 |
| 管理员也无法访问某页面 | 确认用户 is_admin=1；管理员豁免所有权限检查 |
| 忘记 admin 密码 | 删除 `data/mes.db`，运行 `npm run db:reset` 重置数据库（会丢失所有数据） |
