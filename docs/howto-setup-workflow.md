# 如何创建工艺流程

这篇指南教你创建自定义的工艺模板，定义工序步骤、依赖关系和并行规则。

## 前提条件

- 已登录系统（admin 或有 `process_flow` 编辑权限的账号）
- 理解你的生产流程由哪些步骤组成

## 第 1 步: 进入工艺流程页面

点击左侧菜单"工艺流程"。你会看到已有的模板列表。

## 第 2 步: 创建新模板

点击"新增流程"按钮，填写:

- **名称:** 例如"简化热流道流程"
- **描述:** 可选，例如"仅含设计、加工、质检的简化流程"

点击确定后，新模板出现在列表中。

## 第 3 步: 进入模板编辑

点击模板名称，进入详情页。如果还没有步骤，页面会显示空状态。

## 第 4 步: 添加步骤

点击"添加步骤"，依次添加工序:

| 步骤名 | 是否必做 | 可并行 | 说明 |
|--------|---------|--------|------|
| 设计 | 是 | 否 | 第一步 |
| 采购 | 是 | 是 | 可与粗加工并行 |
| 粗加工 | 是 | 是 | 可与采购并行 |
| 精加工 | 是 | 否 | 依赖采购和粗加工都完成 |
| 质检 | 是 | 否 | 最后一步 |

**字段说明:**
- **步骤名:** 工序名称，会显示在订单状态中（如"设计进行中"）
- **是否必做:** 关掉表示可选步骤，可以在订单中跳过
- **可并行:** 打开表示这个步骤可以和其他可并行的步骤同时进行
- **指定执行人:** 可选，填写用户名，用于仪表台"我的待办"统计

## 第 5 步: 设置依赖关系

对于"精加工"，它依赖"采购"和"粗加工"都完成。在步骤编辑中可以指定依赖:

- 步骤 2 (采购) 不需要特别的依赖设置（只需排在精加工前面）
- 步骤 4 (精加工) 设置 `depends_on_step_id` 指向步骤 3 (粗加工)

引擎逻辑: 精加工只有在采购和粗加工都完成时才会出现在"下一步"列表中。

## 第 6 步: 调整顺序

步骤按 `seq` 字段排序。在列表中拖拽可重新排序（前端支持拖拽编辑）。

## 第 7 步: 保存

所有步骤编辑通过 `PUT /api/process-flows/:id/steps` 一次性提交。编辑过程中任何修改都不保存到服务器，所以编辑完记得点保存。

## 验证: 用模板创建订单

1. 进入"订单管理"
2. 点击"新增订单"
3. 填写订单号、产品名
4. 在"工艺模板"下拉中选择你刚创建的模板
5. 创建后打开订单详情，确认步骤已复制，状态为"{第一步名}进行中"

## 注意事项

- **模板 vs 实例:** 修改模板**不会**影响已创建的订单流程实例。如果需要更新已有订单的流程，需要删除订单后重新创建。
- **依赖必须在本流程内:** `depends_on_step_id` 只能指向同一模板内的步骤 ID。
- **seq 连续性:** 虽然引擎不强制 seq 连续，但建议保持 1, 2, 3... 避免混淆。
