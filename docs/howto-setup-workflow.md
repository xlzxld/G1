# 如何创建与管理工艺流程

本指南介绍如何在系统内创建和配置自定义的工艺模板，定义工序步骤、执行人、以及完工判定条件。

## 前提条件

- 已登录系统（需拥有管理员权限，或者被分配了具有 `process_flow` 的 `can_edit=1` 权限账号）。
- 梳理清晰了您车间生产线上的线性工序流程（如：设计 $\to$ 采购 $\to$ 粗加工 $\to$ 精加工 $\to$ 装配 $\to$ 检验 $\to$ 发货）。

## 第 1 步: 进入工艺流程管理

点击左侧导航栏的 **【工艺流程】** 菜单，页面会呈现当前系统中的全部工艺流程模板列表。

## 第 2 步: 新建工艺模板

1. 点击页面右上角的 **【新增流程】** 按钮。
2. 在弹出的对话框中填写：
   - **名称**：工艺模板的简短称呼（如：“简化热流道流程”）。
   - **描述**：对本流程适用场景的解释。
3. 点击“确定”后，模板会新增到列表中。

## 第 3 步: 配置工序步骤

在列表中点击您刚刚新建的模板名称，即可进入该模板的工序配置详情页。

### 添加工序步骤：
点击 **【添加步骤】** 按钮，为流程依次录入各个工序节点。对每个步骤需要配置以下关键参数：

1. **工序名称**：该步骤的具体名称（如：“设计”、“粗加工”、“质检”等），这会直接显示在订单列表和生产进度状态中。
2. **是否必做**：
   - **开启**：该步骤不可跳过，操作人员必须完成该步骤后，订单流程才能继续推进。
   - **关闭**：表示非必做步骤，操作人员可以在订单详情页中选择“跳过”此工序。
3. **指定负责人（Assignee）**：
   - 此输入框已被重构为**动态用户下拉选择框**。
   - 数据实时拉取自系统内的真实操作账号（`/users` 接口），您必须从中选择一位负责人（负责人字段不能为空，以防权责不清）。
4. **完成条件（Completion Condition）**：
   - **手动确认 (manual)**：最基础的流程，操作工点击“完成工序”按钮后即可直接进入下一步。
   - **上传照片 (photo)**：**强控制流程**。设定为此条件时，操作工在点击“完成工序”时，系统会弹出照片上传浮窗，**必须成功上传至少一张现场图纸或检验实操作业照片**，方可确认该步骤完成。

> [!NOTE]
> **关于顺序 (seq)**：工序步骤完全依照 `seq` 顺序号进行线性排列和流转。在保存前，请确认步骤的排布顺序符合您的实际车间生产逻辑。

## 第 4 步: 保存配置

所有步骤在前端编辑完毕后，必须点击右上角的 **【保存】** 按钮，系统会以 `PUT /api/process-flows/:id/steps` 的形式，一次性把全部步骤提交存储至数据库。在点击保存前退出页面，编辑的内容将会丢失。

---

## 验证: 用工艺模板创建订单

1. 进入 **【订单管理】** 页，点击 **【新增订单】**。
2. 输入唯一的订单号和产品名，并在 **【工艺模板】** 下拉菜单中选择您刚刚保存的工艺模板。
3. 提交创建后，打开该订单的详情页。
4. 验证订单底部的工序进度条已成功复制了该模板的所有步骤，且订单的初始状态已被驱动为 `"{第一步工序名}进行中"`。

## 核心注意事项

* **模板与实例完全隔离**：模板的修改**不会**联动修改已经生成的订单。如果某个订单在生产中需要更改步骤，需在模板处修改后重新为该客户生成新订单，或者联系管理员直接修改数据库。
* **线性推进**：系统已不再支持复杂的并行和网状依赖，所有工序一律采用线性依次流转，以最大程度简化车间的实操交互复杂度。
