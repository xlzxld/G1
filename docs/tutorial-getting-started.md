# 快速上手: 运行热流道生产管理系统

这篇教程带你从零开始，使用 Docker Compose 在 5 分钟内构建并运行这套热流道 MES（生产执行系统）。

## 前提条件

运行本系统需要您的电脑安装以下工具：
- **Docker** 与 **Docker Compose** (如 Docker Desktop)
- 终端命令行工具

## 第 1 步: 启动系统容器组

在项目根目录下打开终端，运行以下命令：

```bash
docker-compose up --build
```

### 启动后发生的事情：
1. **自动构建并拉取服务**：
   - 启动 PostgreSQL 数据库容器，并将数据持久化挂载到 `postgres_data` 卷中。
   - 构建 `server-python`（基于 FastAPI）的后端镜像并以开发模式启动。
   - 构建 `client`（基于 Vite + Vue 3）的前端镜像。
2. **端口绑定与访问**：
   - 数据库占用端口：`5432`
   - 后端 API 服务端口：`8888` / `8080` (FastAPI 映射宿主机为 `8080`)
   - 前端 Web 界面端口：`5173`

当控制台停止输出构建信息并显示类似 `Uvicorn running on http://0.0.0.0:8000` 与 Vite 启动消息时，说明所有容器已成功启动。

## 第 2 步: 导入演示种子数据 (Seeding)

容器运行成功后，后端表结构会自动同步。此时数据库内还没有任何数据。我们需要在另一个终端运行种子数据脚本进行初始化。

在项目根目录下打开一个新的终端，执行以下命令：

### 导入基础系统权限与用户：
```bash
docker-compose exec backend python seed.py
```
此脚本会创建系统默认页面权限，并建立三个测试角色。

### 导入用于测试的全套模拟业务数据（可选，推荐）：
```bash
docker-compose exec backend python seed_mock.py
```
此脚本会生成全套模拟客户、库存商品、生产订单以及未读消息通知，用于完整体验系统功能。

## 第 3 步: 登录系统

打开浏览器，访问前端地址：`http://localhost:5173`。

使用下方预设的演示账号登录系统：

## 快速体验核心链路

您可以登录 `admin` 管理员账号，跟随以下路线快速走完一套完整的生产闭环：

1. **新建客户**：进入【客户管理】 $\to$ 点击“新增客户”，填写客户名称与联系人电话。
2. **新增订单**：进入【订单管理】 $\to$ 点击“新增订单”，选择模板为“标准热流道流程”，并关联您刚刚创建的客户。
3. **分配用料**：在订单详情页下方的“用料分配”卡片中，将库存中的零配件预留给当前订单。
4. **上传图纸**：在订单详情中点击“图纸管理” $\to$ 上传任意图纸文件，默认会上传为 `v1` 版本。
5. **推进工序**：
   - 第一步“设计工序”的完成条件被设定为“上传照片”，所以在此工序点击“完成工序”前，您必须为本工序上传一张现场实操照片。
   - 照片上传并提交后，该工序将顺利流转为已完成，且上传的照片会**自动关联并同步呈现在该订单的图纸列表中**。
6. **流程自动结案**：当该订单的所有工序流程都走完（全绿）后，订单状态将自动更新为“已完成”，此时预留锁定库存将被自动**物理扣减**。

## 故障排除

| 常见问题 | 原因分析 | 解决方案 |
|:---|:---|:---|
| 端口冲突 (e.g. 8080/5432 被占用) | 您的电脑上运行了其他 PostgreSQL 实例或 Tomcat/网关占用 8080 端口。 | 修改 `docker-compose.yml` 中的 `ports` 映射（例如将 `"8080:8000"` 改为 `"8081:8000"`），并同步修改前端 proxy 端口。 |
| 无法通过手机或局域网访问 | 前端的配置未绑定局域网 IP。 | 请检查 `docker-compose.yml` 中后端的 `VITE_API_BASE_URL` 和前端的 `VITE_API_BASE_URL`，将其更改为您电脑在局域网内的实际 IP (如 `192.168.x.x`)。 |
| 数据库需要完全重置 | 测试数据过多，想要回到干净的状态。 | 运行 `docker-compose down -v`（删除挂载的数据库卷），然后再运行 `docker-compose up` 重新构建，并重新执行第 2 步的 `seed.py` 命令。 |
